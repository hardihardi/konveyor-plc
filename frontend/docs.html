Autentikasi

Semua endpoint kontrol/parameter/tutup-shift/diagnostik butuh header Authorization: Bearer <token>. Token didapat dari login, usia 8 jam.

POST /api/auth/login
{"username": "supervisor", "password": "••••"}

→ 200 {"access_token": "…", "token_type": "bearer", "expires_in": 28800, "role": "supervisor"}

Akun bawaan (WAJIB ganti password setelah login pertama via POST /api/auth/ganti-password):

Akun bawaan sistem
UsernamePeranHak
supervisorsupervisorKontrol mesin, tutup shift, ekspor
teknisiteknisiKontrol mesin, kalibrasi parameter, I/O test

Daftar seluruh endpoint REST API

GET/api/alarm—Alarm aktif + riwayat 50 terakhir
POST/api/diagnostik/ioteknisiPaksa I/O: kanal sensor|aktuator|interlock|estop, nilai true|false
GET/api/simulasi/objek—Kirim 1 objek simulasi (memicu siklus SORT-1..4)

Contoh Siklus Lengkap (curl)

TOK=$(curl -s -X POST http://host:8600/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"supervisor","password":"xxx"}' | jq -r .access_token)

# Mulai mesin
curl -X POST http://host:8600/api/kontrol \
  -H "Authorization: Bearer $TOK" -H 'Content-Type: application/json' \
  -d '{"perintah":"start"}'

# Simulasikan objek (demo tanpa hardware)
curl http://host:8600/api/simulasi/objek

# Baca counter
curl http://host:8600/api/status | jq .counters

# Tutup shift (arsip ke SQLite + reset)
curl -X POST http://host:8600/api/laporan/tutup-shift \
  -H "Authorization: Bearer $TOK" -H 'Content-Type: application/json' \
  -d '{"username":"supervisor","password":"xxx"}'

# Unduh CSV
curl -OJ http://host:8600/api/laporan/ekspor
